## 关键修改说明

### 1. 添加SystemProperties导入

```java
import android.os.SystemProperties;
```

### 2. 在onCreate方法中添加默认Launcher检查逻辑

在ResolverActivity的onCreate方法中，添加代码检查系统属性并设置默认Launcher：

```java
String launcherPackagename = SystemProperties.get("ro.kte.laucher.package");  
String launcherActivityname = SystemProperties.get("ro.kte.laucher.activity");  
if(launcherPackagename != null && launcherPackagename.length()>0 &&launcherActivityname != null && launcherActivityname.length()>0){  
    if(mResolvingHome){  
        setDefaultLauncher(launcherPackagename, launcherActivityname);  
        finish();  
        return;  
    }
}
```

### 3. 添加setDefaultLauncher方法

新增私有方法用于设置默认Launcher：

- 创建HOME和DEFAULT类别的IntentFilter

- 查询所有符合条件的Launcher应用

- 通过PackageManager设置首选Activity

## 系统属性配置

需要在系统属性中配置以下两个值：

1. **包名属性**：`ro.kte.laucher.package`

   - 格式：Launcher应用的包名，如`com.example.launcher`
2. **Activity名属性**：`ro.kte.laucher.activity`

   - 格式：Launcher的主Activity类名，如`com.example.launcher.MainActivity`

## 使用示例

在系统启动脚本或设备配置中添加：

```properties
setprop ro.kte.laucher.package com.example.launcher  
setprop ro.kte.laucher.activity com.example.launcher.MainActivity
```

## 注意事项

1. 该修改仅影响HOME Intent的解析过程

2. 需要确保配置的包名和Activity名确实存在于系统中

3. 修改生效后，系统将自动跳过Launcher选择界面

4. 此修改需要系统级权限
