#### 背景

在 Android 16 的 WallpaperPicker2 中，系统通过 `PartnerProvider` 机制扫描具有 `com.android.launcher3.action.PARTNER_CUSTOMIZATION` 广播接收器的系统应用，并加载其 `res/xml/wallpapers.xml` 中定义的壁纸资源。GmsSampleIntegration 已声明该接收器，因此只需添加资源即可实现预置壁纸。

***

### 操作步骤

#### 1. 准备图片资源

将壁纸原图和缩略图放入 `vendor/partner_gms/apps/GmsSampleIntegration/res_dhs_full/drawable/` 目录（若使用其他产品目录，请对应调整）。文件命名必须与 XML 中引用一致，例如：

- `wallpaper_1.jpg`（原图）

- `wallpaper_1_thumb.jpg`（缩略图，建议尺寸 200x200 左右）

- `wallpaper_2.jpg`

- `wallpaper_2_thumb.jpg`

**注意**：图片格式支持 PNG/JPEG，文件名不含扩展名，但在 XML 中引用时只需文件名（如 `@drawable/wallpaper_1`）。

#### 2. 创建壁纸配置文件

在 `vendor/partner_gms/apps/GmsSampleIntegration/res_dhs_full/xml/` 目录下新建 `wallpapers.xml`，内容如下：

```xml
<?xml version="1.0" encoding="utf-8"?>
<wallpapers xmlns:android="http://schemas.android.com/apk/res/android">
    <category
        id="gms_wallpapers"
        title="@string/wallpaper_category_title"
        priority="150">

        <static-wallpaper
            id="wp1"
            title="@string/wallpaper_1_title"
            thumbnail="@drawable/wallpaper_1_thumb"
            src="@drawable/wallpaper_1" />

        <static-wallpaper
            id="wp2"
            title="@string/wallpaper_2_title"
            thumbnail="@drawable/wallpaper_2_thumb"
            src="@drawable/wallpaper_2" />
            
    </category>
</wallpapers>

```

**关键属性说明**：

- `<category>` 中的 `android:title` 需要 `android:` 前缀，因为它由 `WallpaperCategory.Builder` 解析。

- `<static-wallpaper>` 中的 `id`、`title`、`thumbnail`、`src` **均不加** `android:` 前缀，因为它们由 `SystemStaticWallpaperInfo` 通过无命名空间方式解析。

- `src` 属性替代了之前错误的 `wallpaper`，务必使用正确。

#### 3. 添加字符串资源

在 `vendor/partner_gms/apps/GmsSampleIntegration/res/values/strings.xml` 中添加壁纸标题：

```xml
<?xml version="1.0" encoding="utf-8"?>
<!-- Copyright (C) 2017 Google Inc. All Rights Reserved. -->
<resources>
    <string name="wallpaper_category_title">Wallpapers</string>
    <string name="wallpaper_1_title">wp1</string>
    <string name="wallpaper_2_title">wp2</string>
</resources>

```

#### 4. 编译并推送 APK

```bash
# 编译 GmsSampleIntegration 模块（具体命令可能因项目而异）  
mmm vendor/partner_gms/apps/GmsSampleIntegration  
# 重新挂载系统分区为可写  
adb root  
adb remount  
# 推送生成的 APK 到设备（路径应与原位置一致）  
adb push out/target/product/.../system_ext/app/GmsSampleIntegration/GmsSampleIntegration.apk /system_ext/app/GmsSampleIntegration/  
# 重启设备使应用生效  
adb reboot
```

#### 5. 清除壁纸应用数据并重新打开

```bash
adb shell pm clear com.android.wallpaper # 包名可能为 com.android.wallpaperpicker 或 com.android.wallpaperpicker2
```

然后打开壁纸选择器（通常为“壁纸和样式”），即可看到新分类及壁纸。

***

### 验证方法

运行以下命令查看日志，确认壁纸被正确解析：

```bash
adb logcat -s SystemStaticWP
```

正常输出应包含：

```text
D SystemStaticWP: fromAttributeSet: package=com.google.android.gmsintegration, category=gms_wallpapers  
D SystemStaticWP: Wallpaper created successfully, title: wp1  
...
```

且最终分类壁纸数量大于 0。

***

### 常见问题排查

| 现象                             | 可能原因                            | 解决方法                                     |
| ------------------------------ | ------------------------------- | ---------------------------------------- |
| 日志显示 `Missing id attribute`    | `<static-wallpaper>` 缺少 `id` 属性 | 添加 `id="xxx"`                            |
| 日志显示 `Missing title attribute` | `title` 属性缺失或拼写错误               | 确保有 `title="@string/xxx"`，且不加 `android:` |
| 日志显示 `Missing src attribute`   | 使用了 `wallpaper` 而非 `src`        | 将属性名改为 `src`                             |
| 壁纸不显示，日志无错误                    | 图片资源缺失或无法解码                     | 检查 APK 中是否包含图片文件，格式是否正确                  |
| 分类未出现                          | 合作伙伴 APK 未被识别                   | 确认应用位于 `/system` 分区，且广播接收器声明正确           |

***

### 注意事项

- 合作伙伴 APK **必须位于系统分区**（如 `/system/priv-app/` 或 `/system_ext/app/`），且使用系统签名。

- 所有图片资源必须包含在 APK 中，可通过 `aapt list <apk> | grep drawable` 检查。

- 若需支持多语言，可在 `strings.xml` 中添加对应翻译。

- 如果希望隐藏系统默认壁纸，可在 `res/values/bools.xml` 中添加 `<bool name="default_wallpapper_hidden">true</bool>`（注意拼写）。

通过以上步骤，即可在 GmsSampleIntegration 应用中成功预置壁纸，无需修改 Java 代码。
