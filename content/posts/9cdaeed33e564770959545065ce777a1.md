## 背景说明

- Android 12默认使用`WallpaperPicker2` APK设置壁纸
- 预置壁纸需集成到系统镜像中，不可卸载
- 壁纸文件需同时提供**原图**和**缩略图**（`_small`后缀）

***

## 实现步骤

### 1. 放置壁纸文件

路径：\
`vendor/partner_gms/apps/GmsSampleIntegration/res/drawable/`

文件命名规范：

wp1.jpg // 原图（建议分辨率 ≥ 1080P）\
wp1\_small.jpg // 缩略图（建议为原图1/4大小）

### 2. 创建配置文件

文件路径：\
`vendor/partner_gms/apps/GmsSampleIntegration/res/values/wallpapers.xml`

内容示例：

```xml

    </string-array>

```

***

## 关键注意事项

1. **命名一致性**\
   `wallpapers.xml`中的`name="wallpapers"`必须与WallpaperPicker2源码中的常量一致：

   ```java
   // 源码路径: WallpaperPicker2/src/com/android/wallpaper/module/PartnerProvider.java
   public static final String WALLPAPER_RES_ID = "wallpapers";
   ```

2. **多壁纸配置**\
   添加多张壁纸时按格式扩展：

   ```xml
   <string-array name="wallpapers" translatable="false">
        <item>wp1</item>
        <item>wp2</item>
        <item>wp3</item>
   </string-array>
   ```

3. **缩略图要求**

   - 文件名必须包含`_small`后缀

   - 建议尺寸：原图的1/4分辨率

   - 格式：JPG/PNG（与原图一致）

4. **编译验证**\
   完成修改后：

   ```bash
   make -j8
   adb reboot bootloader
   fastboot flash system system.img
   ```

***

## 效果验证

1. 设备开机后进入 **设置 → 壁纸 → 我的壁纸**

2. 预置壁纸将出现在系统壁纸列表中

3. 选择壁纸时应正常显示原图/缩略图

> **问题排查**：若壁纸未显示，检查：
>
> 1. XML文件名/路径是否正确
>
> 2. 壁纸文件命名是否规范
>
> 3. 是否执行完整系统编译
